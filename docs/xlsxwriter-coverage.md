# rust_xlsxwriter Coverage Audit

Audited against the pinned crate family declared in `Cargo.toml`.

| Area | Status | v1 policy |
|---|---|---|
| Workbook and worksheets | Covered | JSX components and reverse reader |
| Workbook and worksheet-scoped defined names | Covered in this batch | `Workbook::define_name()` supports global and quoted worksheet-local names; reverse preserves scope/name/formula and rejects hidden or extra authored attributes. |
| Worksheet visibility (visible, hidden, veryHidden) | Covered in this batch | `Worksheet::set_hidden()` and `set_very_hidden()`; reverse preserves states; first sheet must remain visible to retain deterministic active-sheet behavior |
| Active worksheet | Covered in this batch | `Worksheet::set_active()` and workbook `activeTab`; reverse preserves a non-first active worksheet and rejects invalid indices or incompatible selection metadata |
| Selected worksheet tabs / grouped sheets | Covered in this batch | `Worksheet::set_selected()` emits `sheetView@tabSelected`; reverse preserves multiple selected tabs independently from `activeTab` and folds states implied by the writer. Selected hidden sheets and active-but-unselected sheets are rejected with repair guidance because the writer cannot reproduce them. |
| First visible worksheet tab | Covered in this batch | `Worksheet::set_first_tab()` and workbookView `firstSheet`; reverse preserves a non-first visible worksheet as the leftmost tab, omits the default, and rejects invalid indices or hidden targets |
| Worksheet tab color | Covered in this batch | `Worksheet::set_tab_color()` writes RGB tab colors; reverse preserves explicit opaque RGB and rejects theme/indexed/automatic colors |
| Rectangular worksheet tables | Partially covered | `Worksheet::add_table()`, table style/filter/banding flags, totals rows, accessibility metadata via `Table::set_alt_text()` / `set_alt_text_title()` (serialized in the pinned writer's x14 extension), and `TableColumn` headers, totals labels/functions/custom formulas, calculated-column formulas, differential font color/script/emphasis/decoration, solid/pattern RGB fills, number formats, and borders; reverse resolves table relationships and round-trips these properties. `TableColumn::set_header_format()` serializes as ordinary header-cell formatting and supports/reverses regular cell font metadata (name/size/family/charset) there. The pinned writer's `Format::has_dxf_font()` omits font name/size/family/charset from data differential styles; `format` rejects those instead of writing an empty `<dxf>`. It also omits script-only differential formats, so DSL requires another registered differential property with script. Remaining `set_format()` dxf properties and unmodeled column/table metadata remain rejected. The pinned `Table` writer has no public API for table autofilter criteria; worksheet-level `Worksheet::filter_column()` criteria are covered separately. |
| Scalar cell values | Covered | string, number, boolean, blank |
| In-cell boolean checkboxes | Covered in this batch | `Worksheet::insert_checkbox()` / `insert_checkbox_with_format()` and `Format::set_checkbox()`; reverse recognizes the pinned writer's `xfComplement` style extension, validates the workbook `FeaturePropertyBag` relationship/part, and preserves only Boolean cell values |
| Ordinary formula text and scalar cached results; legacy and dynamic array formula text | Covered in this batch | `write_dynamic_array_formula()` / `write_dynamic_formula()`; reverse resolves `cm=1` against the pinned writer's `sheetMetadata` part and preserves bounded/range-less dynamic anchors distinctly from legacy array formulas. Only the XLDAPR dynamic-array metadata subset is accepted; shared/data-table formula groups remain unsupported. |
| Bold and italic cell font | Covered | `Cell` boolean properties; reverse resolves cell style/font IDs |
| Solid and patterned RGB cell, row, and column fills | Covered in this batch | `Format::set_pattern()`, `set_foreground_color()`, and `set_background_color()`; reverse preserves the supported OOXML pattern type and opaque RGB foreground/background fills; gradient/theme/indexed colors remain rejected |
| Opaque RGB font color | Covered in this batch | `Format::set_font_color()`; reverse resolves explicit RGB font colors |
| Literal font name and point size | Covered in this batch | `Format::set_font_name()` / `set_font_size()`; reverse preserves explicit font table values |
| Theme font scheme (body/minor, headings/major, and non-theme) | Covered in this batch | `Format::set_font_scheme()` emits `font/scheme`; reverse preserves major/minor linkage and explicit non-theme font styles for cell, row/column, and rich-text run styles. The writer default `Body` is folded to omission; differential formats remain unsupported for this property and are rejected. |
| Font underline and strikethrough | Covered in this batch | `Format::set_underline()` / `set_font_strikethrough()`; reverse preserves the four underline values and strike state |
| Superscript and subscript cell font | Covered in this batch | `Format::set_font_script()` emits `vertAlign`; external font-table `vertAlign` is reversed to the `script` property |
| Four cell edge borders, diagonal edge/direction, and opaque RGB colors | Covered in this batch | `Format::set_border_*()` and diagonal style/color/type APIs; reverse maps edge style/color/direction; theme/indexed/automatic custom colors and extra metadata are rejected |
| Date and local datetime cells | Covered | ISO DSL value maps to Excel serial plus canonical format; reverse validates the format |
| Row height, hidden state, and outline levels | Covered | `set_row_height()`, `set_row_hidden()`, `group_rows()`, and `group_rows_collapsed()`; reverse preserves per-row outline levels, hidden group members, summary markers, and empty positional rows |
| Default worksheet row height | Covered in this batch | `set_default_row_height_pixels()`; reverse preserves exactly representable `sheetFormatPr@defaultRowHeight` values and rejects fractional-pixel heights |
| Hide unused worksheet rows | Covered in this batch | `Worksheet::hide_unused_rows()` emits `sheetFormatPr@zeroHeight`; reverse preserves this worksheet-wide setting |
| Screen worksheet gridlines | Covered in this batch | `Worksheet::set_screen_gridlines()` emits `sheetView@showGridLines`; reverse preserves hidden/default state; print gridlines remain separate |
| Printed worksheet gridlines | Covered in this batch | `Worksheet::set_print_gridlines()` emits `printOptions@gridLines` plus writer-default `pageSetup`; reverse preserves the supported print options and page setup, rejecting unmodeled attributes |
| Worksheet screen zoom | Covered in this batch | `Worksheet::set_zoom()` emits matching `sheetView@zoomScale` and `zoomScaleNormal`; reverse preserves 10–400 percentages, omits the 100% default, and rejects mismatched normal zoom or other non-default view metadata |
| Worksheet reading direction | Covered in this batch | `Worksheet::set_right_to_left()` emits `sheetView@rightToLeft`; reverse preserves true and canonicalizes default false |
| Worksheet page view mode | Covered in this batch | `set_view_normal()`, `set_view_page_layout()`, and `set_view_page_break_preview()` map `sheetView@view`; reverse preserves active view and the mode-specific zoom attribute, rejecting non-default inactive-view zooms |
| Manual horizontal and vertical page breaks | Covered in this batch | `Worksheet::set_page_breaks()` / `set_vertical_page_breaks()`; reverse preserves manual full-axis break IDs and validates `count`, `manualBreakCount`, max bounds, and duplicates; automatic/partial breaks remain rejected |
| Worksheet print margins | Covered in this batch | `Worksheet::set_margins()` writes six inch-based `pageMargins` values; reverse preserves non-default values and canonicalizes defaults independently for each margin |
| Print scale and fit-to-pages | Covered in this batch | `Worksheet::set_print_scale()` and `set_print_fit_to_pages()` write `pageSetup@scale` / `fitToWidth` / `fitToHeight` with `pageSetUpPr@fitToPage`; reverse checks mutual exclusion, defaults, counts, and incompatibility with manual breaks |
| Page orientation and paper size | Covered in this batch | `Worksheet::set_landscape()`, `set_portrait()`, and `set_paper_size()`; reverse preserves orientation and the unsigned-byte OOXML paper code while rejecting other page-setup metadata |
| First printed-page number | Upstream writer serialization is schema-invalid; not exposed | `Worksheet::set_print_first_page_number(n)` serializes `n` as `pageSetup@useFirstPageNumber` and omits `firstPageNumber`; the former is a boolean OOXML attribute, so numeric values are invalid and the property must remain unavailable until upstream corrects serialization |
| Printed-page centering, monochrome, and draft quality | Covered in this batch | `set_print_center_horizontally()`, `set_print_center_vertically()`, `set_print_black_and_white()`, and `set_print_draft()`; reverse preserves their `printOptions`/`pageSetup` booleans and rejects unsupported options |
| Printed row/column headings and page traversal order | Covered in this batch | `set_print_headings()` and `set_page_order()`; reverse preserves `printOptions@headings` and default/non-default `pageSetup@pageOrder` |
| Print area and repeated print rows/columns | Covered in this batch | `set_print_area()`, `set_repeat_rows()`, and `set_repeat_columns()`; reverse resolves local `_xlnm.Print_Area` / `_xlnm.Print_Titles` formulas and validates sheet IDs and range shape |
| Odd worksheet header/footer text and behavior flags | Covered in this batch | `Worksheet::set_header()` / `set_footer()` plus scale/alignment flags; reverse preserves odd header/footer strings and explicit false flags; image markers and even/first-page variants are rejected |
| Outline summary direction | Covered in this batch | `Worksheet::group_symbols_above()` and `Worksheet::group_symbols_to_left()` map to `outlinePr@summaryBelow` and `summaryRight`; reverse preserves false settings and canonicalizes default true |
| Column width, hidden state, and outline levels | Covered in this batch | `set_column_width_pixels()`, `set_column_hidden()`, `group_columns()`, and `group_columns_collapsed()`; reverse preserves supported `<col>` ranges, outline levels, hidden members, and one-column summary markers |
| Horizontal/vertical cell alignment, text rotation, and reading direction | Covered in this batch | `Format::set_align()`, `Format::set_rotation()`, and `Format::set_reading_direction()`; left/center/right/distributed, top/center/bottom, signed ±90-degree rotation, stacked text, and readingOrder 1/2 reverse; unsupported alignment metadata and OOXML angles outside 0–180/255 are rejected |
| Cell indentation | Covered in this batch | `Format::set_indent()`; DSL requires explicit left/right/distributed alignment to avoid writer normalization; reverse preserves compatible indent values |
| Cell text wrapping | Covered in this batch | `Format::set_text_wrap()`; reverse preserves `wrapText=true` and rejects other advanced alignment settings |
| Cell shrink-to-fit | Covered in this batch | `Format::set_shrink()`; reverse preserves `shrinkToFit=true`; it is mutually exclusive with `wrapText=true` because the writer suppresses it |
| Worksheet auto-filter range, list, blank, custom criteria, and derived filter mode | Covered in this batch | `Worksheet::autofilter()` plus `filter_column()` with `FilterCondition` APIs emits string lists, blank flags, one/two custom predicates with AND/OR, and `sheetPr filterMode`; reverse preserves these and rejects unsupported attributes or date groups |
| Frozen worksheet panes | Covered in this batch | `set_freeze_panes()` and `set_freeze_panes_top_cell()`; reverse preserves row/column splits and pane scroll origin; noncanonical pane selections remain rejected |
| Merged cells | Covered in this batch | `Worksheet::merge_range()`; reverse uses external merge ranges and rejects populated or differently styled interiors |
| Any, list and formula-based data validation (whole, decimal, date, time, text length, custom) | Covered in this batch | `DataValidation::allow_any_value()`, list/formula APIs, and `Worksheet::add_data_validation()`; reverse preserves any rules without a type attribute plus supported type/operator/formula1/formula2, flags and messages; non-default any error styles and extensions are rejected |
| External and internal URL/URI hyperlinks on text cells, including screen tips | Covered in this batch | `Worksheet::write_url_with_format()` plus `Url::set_text()` / `set_tip()`; external relationship targets/fragments, internal `location` anchors, and `tooltip` reverse; unsupported hyperlink metadata is rejected |
| Two-/three-color scales, classic cell comparisons, formula/text rules, data bars, average/date/blank/error/duplicate rules | Covered with supported dxf styles | Color-scale APIs, `ConditionalFormatCell`, `ConditionalFormatFormula`, `ConditionalFormatText`, `ConditionalFormatDataBar`, `ConditionalFormatAverage`, `ConditionalFormatDate`, `ConditionalFormatBlank`, `ConditionalFormatError`, and `ConditionalFormatDuplicate`; reverse validates canonical metadata/formulas, supported emphasis, underline, paired script, RGB font/solid/pattern fill, number-format and four edge-border dxf styles, and exact classic/x14 GUID/range pairing for bars; unsupported extension content remains rejected |
| Classic and x14 built-in, threshold-customized, and per-icon customized icon sets | Partial | `ConditionalFormatIconSet` / `ConditionalFormatCustomIcon`; classic thresholds and x14-only/custom-icon extension ranges, priorities, and `cfIcon` assignments are externally reversed. `greater_than` is not serialized by upstream x14 `cfvo`, so DSL validation rejects true for x14-only/custom rules; all other representable settings are covered |
| Top/bottom count and percent conditional formats | Covered in this batch | `ConditionalFormatTop` / `ConditionalFormatTopRule`; `top10` rank, count-vs-percent, bottom flag, stop-if-true, and supported dxf styles are compiled and reversed; invalid ranks and unsupported differential styles are rejected |
| Custom and common built-in number formats | Covered | `Format::set_num_format()`; reverse preserves custom codes and maps built-in IDs 1–22 and 37–49 |
| Font family and charset | Covered in this batch | `Format::set_font_family()` and `set_font_charset()`; reverse preserves explicit family/charset bytes and rejects unsupported font metadata |
| Quote-prefix cell format | Covered in this batch | `Format::set_quote_prefix()` emits `cellXfs/xf@quotePrefix`; reverse preserves true and validates OOXML booleans |
| Passwordless worksheet protection and cell lock/formula visibility | Covered in this batch | `Worksheet::protect()` / `protect_with_options()` and `Format::set_unlocked()` / `set_hidden()`; reverse preserves supported permission flags and cell protection; password hashes and protected ranges are rejected |
| Border `start`, `end`, and `outline` metadata | Upstream writer API missing; reader-only | `rust_xlsxwriter` 0.99.1 `Format` exposes no start/end border setters or border outline property; external reverse rejects these attributes rather than dropping them |
| Time-only and duration display | Supported as numeric values with number formats | reverse preserves the serial and format code, including elapsed-time formats |
| 1904 date system | Not supported; reverse rejects | writer has no public date-system switch, so converting would shift date serial semantics |
| Excel error cells | Not exposed | reverse reports cell coordinate and specific error token |
| Worksheet ignored-error annotations | Covered in this batch | `Worksheet::ignore_error_range()`; reverse preserves supported Excel error-ignoring flags and rejects malformed or overlapping ranges |
| Rich text strings | Covered in this batch | `Worksheet::write_rich_string()` and `write_rich_string_with_format()`; `<TextRun>` preserves shared- and inline-string run boundaries and supported font properties; cell formatting remains separate; unsupported run font metadata and phonetics fail with repair guidance |
| Phonetic annotations | Not exposed | `<rPh>` and `<phoneticPr>` have no DSL component and are rejected rather than discarded |
| Shared/data-table formulas | Not exposed | shared and data-table formula attributes remain rejected with repair guidance |
| Worksheet active selection and scroll origin | Covered in this batch | `Worksheet::set_selection()` and `set_top_left_cell()`; reverse preserves one contiguous active selection and the visible origin, including the active frozen pane; noncanonical/multi-range pane selections remain rejected |
| Other worksheet view state | Partially covered | custom non-frozen split panes, group selections, and undocumented view metadata remain rejected; page view mode, screen gridlines, reading direction, zoom, frozen panes, visibility, active worksheet, selection, and scroll origin are covered |
| Core document properties | Covered in this batch | Workbook `title`, `subject`, `author`, `keywords`, and `description` map to `DocProperties`; reverse preserves supported properties and rejects unmodeled authored metadata; generated timestamps are ignored |
| Unknown OPC/XLSX parts | Not exposed | package part allowlist rejects unknown parts |
| Row and column default formats | Covered in this batch | `Worksheet::set_row_format()` / `set_column_format()`; reverse resolves row `s` and column `style` through the existing style-table parser and emits the same supported format properties; unsupported style-table semantics remain errors |
| Column best-fit flag | No writer serialization equivalent | `rust_xlsxwriter::autofit()` computes pixel widths; the pinned writer does not serialize OOXML `bestFit`, so reverse rejects authored `bestFit` rather than approximating it |
| Other row/column metadata | Writer API/OOXML subset only | Existing height, hidden and outline properties remain covered; unsupported row/column attributes are rejected with their names and repair suggestions |
| Cell/row/column formats | Bold/italic, literal font name/size/family/charset/color, underline/strikethrough/script, quote prefix, rich-text run font properties, four edge borders, diagonal border/direction, solid and patterned opaque-RGB fills, alignment/rotation/reading direction/wrap/indent, and number formats covered | reverse resolves cell XF/font/fill/border indices and rich-text run properties; all supported `FormatPattern` values round-trip with opaque RGB foreground/background colors; gradients and theme/indexed/automatic colors remain rejected |
| Average/standard-deviation, date, blank/non-blank, error/non-error, duplicate/unique conditional formats | Covered in this batch | `ConditionalFormatAverage`, `ConditionalFormatDate`, `ConditionalFormatBlank`, `ConditionalFormatError`, and `ConditionalFormatDuplicate`; reverse validates writer attributes/formulas, optional supported differential styles, and rule-to-type consistency |
| Date-group auto-filter criteria | No matching public writer API; reverse rejects | The pinned `FilterCondition` API does not expose date grouping |
| Legacy cell notes | Supported writer subset; `Note::set_object_movement()` not exposed | `Worksheet::insert_note()` and `Note` setters are wrapped for text, author prefix, visibility, integer-pixel dimensions, RGB background, note font, and alt text. Reverse follows comments/VML relationships and verifies anchor/offset geometry by regenerating it from recovered row/column layout; unsupported rich-text runs, non-note shapes, or non-reproducible movement geometry are rejected |
| Threaded comments | Not exposed; reverse rejects package parts | `rust_xlsxwriter` 0.99.1 does not provide threaded-comment authoring |
| Charts, images, pivots, macros | Not exposed; reverse rejects package parts | add only with external reverse support |

This is a staged audit, not a claim that all public `rust_xlsxwriter` writer APIs
are wrapped. Each subsequent feature batch must classify writer support and
reader parity before adding DSL fields.
