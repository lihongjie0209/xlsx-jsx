# rust_xlsxwriter Coverage Audit

Audited against the pinned crate family declared in `Cargo.toml`.

| Area | Status | v1 policy |
|---|---|---|
| Workbook and worksheets | Covered | JSX components and reverse reader |
| Chartsheets | Covered in this batch | `Workbook::add_chartsheet()` preserves an ordered chart sheet with one full-sheet chart and worksheet-qualified series formulas. Reverse recognizes external `chartsheet` parts and absolute chart anchors without a manifest, preserving name/visibility/chart properties. Only the pinned writer's default landscape canvas is representable; active/selected/first-tab chartsheets, chart-sheet-local defined names, non-default viewport geometry, and extra drawings are rejected. |
| Core workbook metadata category/status | Covered in this batch | `DocProperties::set_category()` / `set_status()` map to `cp:category` / `cp:contentStatus`; IR validation and reverse preserve both from external `docProps/core.xml` without a manifest. Other authored core fields remain rejected unless modeled. |
| Extended workbook metadata | Covered in this batch | `DocProperties::set_manager()` / `set_company()` / `set_hyperlink_base()` map to `Manager`, `Company`, and `HyperlinkBase` in `docProps/app.xml`; reverse preserves these authored values and rejects unknown app properties while ignoring known structure-derived app fields. |
| Custom workbook document properties | Covered in this batch | `DocProperties::set_custom_property()` supports string, `i32`, `f64`, boolean, and date-time values in `docProps/custom.xml`; reverse validates package relationship/content type and preserves property name, type, value, and order. |
| Workbook and worksheet-scoped defined names | Covered in this batch | `Workbook::define_name()` supports global and quoted worksheet-local names; reverse preserves scope/name/formula and rejects hidden or extra authored attributes. |
| Worksheet visibility (visible, hidden, veryHidden) | Covered in this batch | `Worksheet::set_hidden()` and `set_very_hidden()`; reverse preserves states; first sheet must remain visible to retain deterministic active-sheet behavior |
| Active worksheet | Covered in this batch | `Worksheet::set_active()` and workbook `activeTab`; reverse preserves a non-first active worksheet and rejects invalid indices or incompatible selection metadata |
| Selected worksheet tabs / grouped sheets | Covered in this batch | `Worksheet::set_selected()` emits `sheetView@tabSelected`; reverse preserves multiple selected tabs independently from `activeTab` and folds states implied by the writer. Selected hidden sheets and active-but-unselected sheets are rejected with repair guidance because the writer cannot reproduce them. |
| First visible worksheet tab | Covered in this batch | `Worksheet::set_first_tab()` and workbookView `firstSheet`; reverse preserves a non-first visible worksheet as the leftmost tab, omits the default, and rejects invalid indices or hidden targets |
| Worksheet tab color | Covered in this batch | `Worksheet::set_tab_color()` writes RGB tab colors; reverse preserves explicit opaque RGB and rejects theme/indexed/automatic colors |
| Worksheet VBA code name | Covered in this batch | `Worksheet::set_vba_name()` writes `sheetPr@codeName`; reverse preserves the name for macro-free and macro-enabled worksheet parts, validating Excel's 31-character identifier rules and uniqueness |
| Workbook VBA code name | Covered in this batch | `Workbook::set_vba_name()` writes `workbookPr@codeName`; reverse preserves it for macro-free and macro-enabled workbooks and validates the Excel identifier rules |
| Rectangular worksheet tables | Partially covered | `Worksheet::add_table()` and `Table::set_header_row(false)` preserve headered/headerless ranges; headerless columns retain explicit OOXML column names and have no worksheet header-cell formatting. Table style/filter/banding flags, totals rows, accessibility metadata via `Table::set_alt_text()` / `set_alt_text_title()` (serialized in the pinned writer's x14 extension), and `TableColumn` headers, totals labels/functions/custom formulas, calculated-column formulas, differential font name/size/family/charset/color/script/emphasis/decoration, solid/pattern RGB fills, number formats, and borders; reverse resolves table relationships and round-trips these properties. `TableColumn::set_header_format()` serializes as ordinary header-cell formatting and accepts the supported `Cell` format property set; reverse preserves it as header `Cell` formatting. The compiler repairs the pinned writer's omission of script-only differential formats, `vertAlign`, and font name/size/family/charset in data differential fonts. Remaining `set_format()` dxf properties and unmodeled column/table metadata remain rejected. The pinned `Table` writer has no public API for table autofilter criteria; worksheet-level `Worksheet::filter_column()` criteria are covered separately. |
| Scalar cell values | Covered | string, number, boolean, blank |
| In-cell boolean checkboxes | Covered in this batch | `Worksheet::insert_checkbox()` / `insert_checkbox_with_format()` and `Format::set_checkbox()`; reverse recognizes the pinned writer's `xfComplement` style extension, validates the workbook `FeaturePropertyBag` relationship/part, and preserves only Boolean cell values |
| Ordinary formula text and scalar cached results; legacy and dynamic array formula text | Covered in this batch | `write_dynamic_array_formula()` / `write_dynamic_formula()`; reverse resolves `cm=1` against the pinned writer's `sheetMetadata` part and preserves bounded/range-less dynamic anchors distinctly from legacy array formulas. Only the XLDAPR dynamic-array metadata subset is accepted; shared/data-table formula groups remain unsupported. |
| Bold and italic cell font | Covered | `Cell` boolean properties; reverse resolves cell style/font IDs |
| Solid and patterned RGB cell, row, and column fills | Covered in this batch | `Format::set_pattern()`, `set_foreground_color()`, and `set_background_color()`; reverse preserves the supported OOXML pattern type and opaque RGB foreground/background fills; gradient/theme/indexed colors remain rejected |
| Opaque RGB font color | Covered in this batch | `Format::set_font_color()`; reverse resolves explicit RGB font colors |
| Literal font name and point size | Covered in this batch | `Format::set_font_name()` / `set_font_size()`; reverse preserves explicit font table values |
| Theme font scheme (body/minor, headings/major, and non-theme) | Covered in this batch | `Format::set_font_scheme()` emits `font/scheme`; reverse preserves major/minor linkage and explicit non-theme font styles for cell, row/column, rich-text run styles, and table-column differential formats. The compiler restores scheme metadata omitted by the pinned writer's DXF font-presence check; table DXFs preserve explicit body/minor distinctly. |
| Font underline and strikethrough | Covered in this batch | `Format::set_underline()` / `set_font_strikethrough()`; reverse preserves the four underline values and strike state |
| Superscript and subscript cell font | Covered in this batch | `Format::set_font_script()` emits `vertAlign`; external font-table `vertAlign` is reversed to the `script` property |
| Four cell edge borders, diagonal edge/direction, and opaque RGB colors | Covered in this batch | `Format::set_border_*()` and diagonal style/color/type APIs; reverse maps edge style/color/direction; theme/indexed/automatic custom colors and extra metadata are rejected |
| Date and local datetime cells | Covered | ISO DSL value maps to Excel serial plus canonical format; reverse validates the format |
| Row height, hidden state, and outline levels | Covered | `set_row_height()`, `set_row_hidden()`, `group_rows()`, and `group_rows_collapsed()`; reverse preserves per-row outline levels, hidden group members, summary markers, and empty positional rows |
| Default worksheet row height | Covered in this batch | `set_default_row_height_pixels()`; reverse preserves exactly representable `sheetFormatPr@defaultRowHeight` values and rejects fractional-pixel heights |
| Hide unused worksheet rows | Covered in this batch | `Worksheet::hide_unused_rows()` emits `sheetFormatPr@zeroHeight`; reverse preserves this worksheet-wide setting |
| Screen worksheet gridlines | Covered in this batch | `Worksheet::set_screen_gridlines()` emits `sheetView@showGridLines`; reverse preserves hidden/default state; print gridlines remain separate |
| Printed worksheet gridlines | Covered in this batch | `Worksheet::set_print_gridlines()` emits `printOptions@gridLines` plus writer-default `pageSetup`; reverse preserves the supported print options and page setup, rejecting unmodeled attributes |
| Worksheet screen zoom | Covered in this batch | `Worksheet::set_zoom()` emits matching `sheetView@zoomScale` and `zoomScaleNormal`; reverse preserves 10–400 percentages, omits the 100% default, and rejects mismatched normal zoom or other non-default view metadata |
| Worksheet reading direction | Covered in this batch | `Worksheet::set_right_to_left()` emits `sheetView@rightToLeft`; reverse preserves true and canonicalizes default false |
| Worksheet page view mode | Covered in this batch | `set_view_normal()`, `set_view_page_layout()`, and `set_view_page_break_preview()` map `sheetView@view`; reverse preserves active view and the mode-specific zoom attribute, rejecting non-default inactive-view zooms |
| Manual horizontal and vertical page breaks | Covered in this batch | `Worksheet::set_page_breaks()` / `set_vertical_page_breaks()`; reverse preserves manual full-axis break IDs and validates `count`, `manualBreakCount`, max bounds, and duplicates; automatic/partial breaks remain rejected |
| Worksheet print margins | Covered in this batch | `Worksheet::set_margins()` writes six inch-based `pageMargins` values; reverse preserves non-default values and canonicalizes defaults independently for each margin |
| Print scale and fit-to-pages | Covered in this batch | `Worksheet::set_print_scale()` and `set_print_fit_to_pages()` write `pageSetup@scale` / `fitToWidth` / `fitToHeight` with `pageSetUpPr@fitToPage`; reverse checks mutual exclusion, defaults, counts, and incompatibility with manual breaks |
| Page orientation and paper size | Covered in this batch | `Worksheet::set_landscape()`, `set_portrait()`, and `set_paper_size()`; reverse preserves orientation and the unsigned-byte OOXML paper code while rejecting other page-setup metadata |
| First printed-page number | Upstream writer serialization is schema-invalid; not exposed | `Worksheet::set_print_first_page_number(n)` serializes `n` as `pageSetup@useFirstPageNumber` and omits `firstPageNumber`; the former is a boolean OOXML attribute, so numeric values are invalid and the property must remain unavailable until upstream corrects serialization |
| Printed-page centering, monochrome, and draft quality | Covered in this batch | `set_print_center_horizontally()`, `set_print_center_vertically()`, `set_print_black_and_white()`, and `set_print_draft()`; reverse preserves their `printOptions`/`pageSetup` booleans and rejects unsupported options |
| Printed row/column headings and page traversal order | Covered in this batch | `set_print_headings()` and `set_page_order()`; reverse preserves `printOptions@headings` and default/non-default `pageSetup@pageOrder` |
| Print area and repeated print rows/columns | Covered in this batch | `set_print_area()`, `set_repeat_rows()`, and `set_repeat_columns()`; reverse resolves local `_xlnm.Print_Area` / `_xlnm.Print_Titles` formulas and validates sheet IDs and range shape |
| Odd worksheet header/footer text, behavior flags, and raster images | Covered in this batch | `Worksheet::set_header()` / `set_footer()`, scale/alignment flags, `set_header_image()` / `set_footer_image()` and `HeaderImagePosition`; `<HeaderImage>` / `<FooterImage>` preserve PNG/JPEG/GIF/BMP media through the independent `legacyDrawingHF` VML relationships without a manifest. | Column width, hidden state, and outline levels | Covered in this batch | `set_column_width_pixels()`, `set_column_hidden()`, `group_columns()`, and `group_columns_collapsed()`; reverse preserves supported `<col>` ranges, outline levels, hidden members, and one-column summary markers |
| Horizontal/vertical cell alignment, text rotation, and reading direction | Covered in this batch | `Format::set_align()`, `Format::set_rotation()`, and `Format::set_reading_direction()`; left/center/right/distributed, top/center/bottom, signed ±90-degree rotation, stacked text, and readingOrder 1/2 reverse; unsupported alignment metadata and OOXML angles outside 0–180/255 are rejected |
| Cell indentation | Covered in this batch | `Format::set_indent()`; DSL requires explicit left/right/distributed alignment to avoid writer normalization; reverse preserves compatible indent values |
